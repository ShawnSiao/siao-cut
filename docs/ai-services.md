# 可配置 AI 服务

SiaoCut 的文本 AI 辅助可以使用本机 Codex，也可以使用用户自行配置的 LLM API。未安装 Codex 时，仍可通过 API 完成字幕润色、校对、标点、编辑、翻译、说话人命名和一键工作流字幕翻译。

## 产品边界

- 本版本只处理文本、字幕段 ID、时间戳、目标语言、术语表、说话人文本证据和响应结构。
- 不向远程服务发送视频、音频、本机媒体路径、数据库或凭据。
- AI 结果只进入待审核流程，不直接修改项目。
- 不支持视觉模型、视频帧、音频上传、云端项目同步和跨厂商自动切换。

## 支持的协议

| 服务 | 协议 |
| --- | --- |
| OpenAI | Responses API |
| Anthropic | Messages API |
| Gemini | Generate Content API |
| DeepSeek、Kimi、GLM | OpenAI-compatible Chat Completions |
| 其他兼容服务 | 自定义 OpenAI-compatible Chat Completions |

内置服务固定使用官方端点。自定义兼容服务允许多个实例。公网端点必须使用 HTTPS；HTTP 只允许 `localhost`、`127.0.0.1` 和 `::1`。端点不能包含用户信息、查询参数或片段。

## 配置与凭据

环境配置分为「本地功能」和「AI 服务」两个页签。AI 服务页提供服务列表、模型、默认标记、最近测试状态、模型获取、连接测试和代理配置。

API Key 保存到 Windows Credential Manager，凭据目标格式为：

```text
app.siaocut.desktop/ai-service/{serviceId}
```

配置文件和数据库只记录「未配置」或「已保存」，不保存或回显 API Key。空白 API Key 不覆盖已保存凭据；删除凭据使用独立确认操作。

## 执行确认

每次 AI 辅助执行前必须确认：

- 执行方式：「AI 服务」「本机 Codex」或「复制提示词」。
- 接收服务和本次模型。
- 字幕段数、字符数和时间范围。
- 翻译术语表或说话人文本证据。
- 可能产生的 API 用量。
- 只发送文本任务载荷的数据边界。

确认页临时修改模型不会改写服务默认模型。API 默认服务优先于本机 Codex；没有可用执行器时使用「复制提示词」。服务、凭据或代理配置变化后，旧任务必须重新确认。

## 失败、重试与恢复

超时、`429` 和 `5xx` 在同一服务内最多自动重试两次，默认等待 1 秒和 2 秒。存在 `Retry-After` 时采用厂商值，单次等待不超过 30 秒。鉴权失败、模型不存在、响应格式错误和结构校验失败不自动重试。

SiaoCut 不自动切换服务或厂商。切换服务或模型会创建新的运行并重新执行全部批次。批次默认不超过 60 段或 12,000 个字符；单条字幕最多 24,000 个字符。

运行记录保存执行方式、服务和网络修订号、模型、厂商请求 ID、用量摘要和重试次数。原始 HTTP 请求体、厂商响应包、完整提示词和 API Key 不进入日志或数据库。

## 卸载

- 升级和静默卸载保留 AI 配置与凭据。
- 交互式卸载会询问是否删除 AI 配置和凭据。
- 删除 AI 配置不会删除项目、媒体或本地资源。
