# 首次使用 SiaoCut

[简体中文](first-run.md) | [English](first-run.en.md)

当前提供 Windows x64 本地预览版，未签名、自动更新关闭。先用一段有权处理、保留原始副本的短视频走通流程，再处理重要项目。

## 1. 获取预览版

从 [GitHub 预览发布页](https://github.com/ShawnSiao/siao-cut/releases/tag/local-preview-0.2.0-20260913-r2)下载名称含 `local-preview` 的安装器及 `SHA256SUMS`，在 PowerShell 中检查下载文件：

```powershell
Get-FileHash -LiteralPath '.\SiaoCut_0.2.0_local-preview_20260913-r2_x64-setup.exe' -Algorithm SHA256
```

将输出与 `SHA256SUMS` 中对应文件的值逐字比较。哈希一致只说明下载完整，不代表安装器已签名。阅读发布页的实机验收限制后再决定是否安装；不要为安装而关闭系统防护。

安装包只包含应用和 Core，不含 FFmpeg、Whisper 或模型。首次打开后出现组件未配置状态，不表示安装失败。

## 2. 准备本地组件

在运行环境设置中查看 FFmpeg、Whisper 和模型状态，按应用显示的来源准备所需组件，选择可用转写模型。先使用当前硬件支持的路径；不要仅凭显卡驱动存在就认定 GPU 后端可用。MOSS 多人转写是额外实验能力，首次体验无需配置。

## 3. 完成一次本地交付

1. 导入短视频，确认预览可播放。
2. 选择模型并开始本地转写，等待任务完成。
3. 播放开头、中间和结尾，检查字幕时间与文字；修正一条明显错误。
4. 在「质量」检查错误，在「历史」查看已保存版本。
5. 在「导出」先导出 SRT 或 VTT 到独立文件，打开检查文字和时间；需要视频时再导出独立 MP4。
6. 关闭并重新打开项目，确认字幕修改仍存在，原始视频未被覆盖。

第一次不必启用 Agent。上述流程使用本地组件；未配置 Codex 或没有付费模型账号时，也可先完成转写、手工校对和导出。

## 4. 按需使用 Agent

可选择已配置的「AI 服务」、已安装并登录的「本机 Codex」，或「复制提示词／手工交接」。没有 Codex 时，可以配置可用的 LLM API；没有 AI 账号时仍可完成本地转写和手工编辑。

点击「开始 AI 辅助」后，检查接收方、模型、实际文本范围和费用提示，再确认发送。结果回来后在「审阅」查看差异，决定应用或保留原文。本机 Codex 也可能调用远程模型；手工交接需要能够执行协议的 Agent，不提供免费模型服务。配置步骤见 [AI 服务说明](ai-services.md)。

## 遇到问题时

| 现象 | 下一步 |
| --- | --- |
| 组件未配置、无法开始转写 | 检查运行环境、模型选择和组件路径 |
| 转写耗时较长 | 查看实际阶段，先用短片验证；性能取决于硬件与模型 |
| Agent 不可用 | 继续本地手工流程，另行确认账号与 CLI 状态 |
| 原片缺失或内容变化导致导出被阻止 | 找回对应的原片副本，不绕过完整性检查 |
| 项目恢复或升级异常 | 保留现场，退出应用后备份整个数据目录；不要覆盖唯一副本 |

默认数据目录为 `%LOCALAPPDATA%\SiaoCut`；设置了 `SIAOCUT_HOME` 时以实际目录为准。原始媒体可能在目录外，需要单独保留。反馈只提供版本、操作步骤、错误码和脱敏截图，不上传私人字幕、原始媒体或凭据。

更多操作见[用户手册](workbench-user-guide.md)。签名、完整 Windows 安装升级与真实媒体／AI 回归仍须单独验收；完成本指南不能替代正式发布验收。
