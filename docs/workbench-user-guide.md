# SiaoCut 用户手册

本手册说明 SiaoCut 桌面工作台的主要模块、界面信息和推荐操作顺序。适用于当前源码开发版本；界面与规则可能随版本调整。

SiaoCut 以字幕文稿为主要编辑入口。媒体处理、转写、音频分析和说话人分析在本机运行。Agent 只接收文本、时间戳和结构约束，不接收媒体文件、媒体路径或项目数据库。

## 1. 推荐工作流程

1. 导入本地媒体，或在确认拥有处理权限后导入公开单视频 URL。
2. 检查本机运行环境并选择转写模型。
3. 完成本地转写，校对字幕正文和时间。
4. 按需要运行 Agent 工作流。
5. 在「审阅」中逐条决定保留原文或应用建议。
6. 在「质量」中处理字幕错误和提醒。
7. 在「分析」中试听语音、音频和说话人证据。
8. 在「历史」中检查可恢复版本。
9. 在「导出」中选择字幕或视频格式并完成导出前检查。

任何 Agent 建议、语音证据或分析风险都不会自动修改原片。

### 1.1 一键工作流预设

| 预设 | 固定路径 | 审阅要求 |
| --- | --- | --- |
| 快速初稿 | 导入 → 转写 → 审计 → 导出 | 不运行粗剪检测和 Agent；只允许原文字幕，成品会标记为未经建议审阅的初稿。 |
| 平衡审阅 | 导入 → 转写 → 粗剪建议 → 可选翻译 → 审阅 → 审计 → 导出 | 默认路径；存在待审建议时暂停，应用或保留后继续。 |
| 精细交付 | 导入 → 转写 → 本地音频分析 → 粗剪建议 → 可选翻译 → 审阅 → 审计 → 导出 | 即使没有建议，也必须确认完成审阅。 |

自动工作流的路径由 Core 固定，关闭应用或任务中断后可从统一状态区域继续。取消「精细交付」时，其音频分析子任务会同时取消；继续时复用原任务，不重复创建。AI 翻译仍需明确选择服务、模型和文本发送范围，结果只进入待审区。

## 2. 工作台结构

打开项目后，工作台主要分为以下区域：

- 「素材预览」：播放原片、查看字幕效果和定位当前时间。
- 「文稿」：编辑字幕，搜索和替换文字，拆分、合并或调整字幕时间。
- 「字幕时间轴」：查看字幕顺序、说话人颜色和已经应用的软剪辑。
- 「集中工作抽屉」：包含「审阅」「质量」「分析」「历史」「导出」5 个模块。
- 「统一状态」：只显示当前最高优先级操作；展开后查看其他待操作、失败、中断或运行中的后台任务。
- 「专注审阅」：在当前窗口重排播放器和审阅队列，不创建独立窗口，也不重新加载媒体。

处理字幕时，先在文稿列表选择字幕段。分析定位、说话人分配和词级剪辑都会以当前字幕段为操作对象。

## 3. 审阅

「审阅」用于创建 Agent 任务、查看 Agent 运行状态，以及决定是否应用 Agent 建议和软剪辑。

### 3.1 Agent 工作流

| 工作流 | 主要能力 | 不应替代的人工判断 |
| --- | --- | --- |
| 润色 | 改善表达，修正明显转写错误，不改变事实 | 事实核对、语气选择 |
| 校对 | 修正错别字、标点和明显转写错误 | 专有名词和人物名称确认 |
| 补充标点 | 只补充标点和必要的英文句首大小写，保留口述词 | 断句风格和字幕节奏 |
| 精简文稿 | 识别重复、跑题和失败重录，提出文本修改 | 是否应该删除内容 |
| 翻译字幕 | 按字幕段翻译，保留原意和术语 | 术语、语境和文化表达 |
| 识别人物姓名 | 根据自我介绍或明确文本证据建议显示名 | 证据不足时的人物身份判断 |

翻译工作流需要先选择目标语言。项目术语表采用每行一项的格式：

```text
原文=目标文本
```

术语表保存新版本后，相关译文会被标记为需要重新检查。

### 3.2 「交给本机 Codex」

适用于本机已安装并登录兼容 Codex CLI 的情况。

操作流程：

1. 选择 Agent 工作流。
2. 点击「交给本机 Codex」。
3. 等待批次处理完成。
4. 在建议进入「待审」后逐条检查差异。

长文稿会按字幕段拆成多个批次。界面中的「批次 4 / 14」表示正在处理第 4 批，共 14 批，不表示已经应用 4 批修改。

本机 Codex 在隔离环境中运行。结果完成后只进入待审队列，不会直接改写字幕。

### 3.3 「手工交接」

适用于以下情况：

- Codex CLI 尚未安装或未登录。
- 需要使用另一个本机 Agent 环境。
- 需要人工控制领取、处理和提交步骤。

操作流程：

1. 选择工作流并点击「手工交接」。
2. 复制界面生成的完整交接说明。
3. 将说明粘贴到能够访问本机 SiaoCut Core 的 Agent 环境。
4. 外部 Agent 按说明领取任务、读取文本载荷、发送心跳并提交结构化结果。
5. 回到 SiaoCut 查看待审差异。

「手工交接」不是复制一段普通提示词。交接内容包含任务 ID、工作者身份、租约和提交约束。领取后的租约只对当前任务尝试有效。

### 3.4 两种处理方式的区别

| 对比项 | 交给本机 Codex | 手工交接 |
| --- | --- | --- |
| 启动方式 | SiaoCut 自动启动 Codex CLI | 人工复制交接说明 |
| 批次处理 | 自动拆分和连续处理 | 外部 Agent 按交接协议处理 |
| 任务租约 | SiaoCut 自动管理 | 外部 Agent 必须使用交接中的租约 |
| 状态回传 | 自动显示批次和进度 | 外部 Agent 需要发送心跳 |
| 结果去向 | 待审队列 | 待审队列 |
| 是否自动应用 | 否 | 否 |
| 媒体是否交给 Agent | 否 | 否 |

### 3.5 如何审阅建议

每条建议包含：

- 原文。
- Agent 建议。
- 修改原因。
- 置信度。
- 当前文本；只在项目内容已经变化时显示。

可执行的操作：

- 「定位原文」：选中对应字幕段。
- 「保留原文」：拒绝当前建议。
- 「应用建议」：将建议写入项目并创建可恢复版本。
- 「全部保留」：拒绝当前任务中的全部建议。
- 「全部应用」：应用当前任务中所有无冲突建议。

出现冲突时，说明任务创建后对应字幕已经变化。旧建议不会覆盖新内容，应保留当前文本或重新创建任务。

### 3.6 运行状态与恢复

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 等待本机 Agent | 任务已经排队 | 等待启动 |
| 本机 Agent 处理中 | 正在处理文本批次 | 可继续编辑不相关内容，但不要改动任务基线字幕 |
| 正在校验并提交建议 | 所有批次正在合并和校验 | 等待进入待审 |
| 建议已进入待审 | 结果已保存，字幕尚未修改 | 逐条审阅 |
| 运行已中断 | 本机进程异常退出 | 展开详情后显式继续 |
| 运行失败 | 输出、任务版本或提交校验未通过 | 先查看技术详情，再决定继续 |
| 已取消 | 本次运行已停止 | 需要时重新创建或继续 |

「显式继续」会复用同一项目版本和相同批次范围下已经完成的安全结果，只重新处理未完成批次。项目版本或批次范围已经变化时，会按当前项目重新建立任务批次。

## 4. 质量

「质量」用于检查字幕结构、时间和阅读负担。错误可能阻止字幕导入或导出；提醒用于人工复核，不会自动改写字幕。

### 4.1 界面信息

- 「错误」：时间无效、字幕为空或超出媒体范围等结构问题。
- 「提醒」：字幕过长、阅读速度过快、间隔过短等可读性问题。
- 「全部」：显示所有问题。
- 问题时间：点击后定位对应字幕段。

优先处理错误，再处理提醒。处理完成后重新查看质量状态。

### 4.2 当前检查规则

| 检查项 | 当前规则 | 说明 |
| --- | --- | --- |
| 字幕为空 | 去除空白后没有文本 | 错误 |
| 时间无效 | 结束时间不晚于开始时间 | 错误 |
| 超出媒体范围 | 字幕结束时间晚于原片时长 | 错误 |
| 时间重叠 | 当前字幕与上一条字幕重叠 | 提醒 |
| 显示时间过长 | 超过 `8 秒` | 提醒 |
| 单行字符过多 | 每个显式换行内超过 `42` 个非空白 Unicode 字符 | 提醒 |
| 英文字幕行数过多 | 英文字幕超过 `2` 行 | 提醒 |
| 阅读速度过快 | 非空白字符数除以显示时长超过 `20 CPS` | 提醒 |
| 字幕间隔过短 | 相邻字幕间隔小于 `0.12 秒` | 提醒 |

`CPS` 表示每秒字符数。

当前阈值属于 SiaoCut Creator Beta 固定规则，不是所有平台和语言共用的行业标准。中文、英文、日文和韩文的专业交付标准可能采用不同的行长、计数方式和阅读速度。项目需要特定平台交付时，应以目标平台规范为准。

### 4.3 使用方式

1. 点击「错误」筛选结构问题。
2. 点击问题项定位字幕。
3. 修正文稿或调整时间。
4. 点击「提醒」检查阅读体验。
5. 在播放器中实际观看字幕节奏。
6. 未发现阻止导出的问题后，进入「导出」。

字符数和 CPS 只能提供初步提醒。实际可读性还取决于字体、字号、画面比例、字幕位置、语言和内容难度。

## 5. 分析

「分析」由语音节奏、音频质量、说话人轨和词级时间 4 组本地证据组成。主要用途是发现位置并试听确认。

### 5.1 语音节奏

| 信息 | 含义 | 使用方式 |
| --- | --- | --- |
| 词条/分钟 | 按实际发声时间计算的语速 | 比较同一项目中的快慢段落 |
| 停顿 | 相邻词间隔达到 `0.8 秒` | 点击定位并试听 |
| 长停顿 | 相邻词间隔达到 `1.5 秒` | 检查冷场、忘词或剪辑停顿 |
| 口头语 | 「嗯、呃、额、uh、um」等固定词表 | 判断是否需要保留或剪除 |
| 低置信度 | ASR 置信度低于 `75%` | 优先校对转写正文 |

「低置信度」表示转写模型不确定，不代表发音一定存在问题。「词条」来自 ASR 词级时间，不等同于语言学分词。

当前面板最多显示前 2 个停顿和前 3 个口头语或低置信度证据。点击证据会选择对应字幕段。

缺少词级时间时显示「证据不足」，不会估算语速或停顿。

### 5.2 音频质量

点击「开始本地分析」后，固定 FFmpeg 会检查：

| 信息 | 含义 |
| --- | --- |
| 综合响度 LUFS | 整段媒体的平均主观响度 |
| 真峰值 dBFS | 音频最高峰值 |
| 待确认风险 | 超过固定阈值的风险数量 |
| 静音秒数 | 检测到的静音区间总时长 |

当前阈值：

- 静音：低于 `-40 dB` 且持续至少 `0.8 秒`。
- 疑似削波：真峰值不低于 `-0.1 dBFS`。
- 响度偏低：低于 `-24 LUFS`。
- 响度偏高：高于 `-14 LUFS`。

操作流程：

1. 点击「开始本地分析」。
2. 查看风险类型、实测值和阈值。
3. 点击风险定位原片。
4. 试听确认是真实问题还是合理内容。
5. 在「审阅」中查看完整风险列表。

「分析」面板最多显示前 3 项音频风险。静音风险具有具体时间范围；响度和真峰值是全片统计，目前不能指出具体发生位置。

音频质量分析不会分类任意噪声、混响、背景音乐或人声清晰度。

### 5.3 说话人轨

说话人轨显示：

- 识别出的说话人数。
- 说话区间数量。
- 当前字幕关联的说话人。
- 时间轴上的说话人颜色。
- 模型和运行时版本。

首次使用需要在「运行环境」中检查模型来源、许可证、大小和 SHA-256，并明确安装可选模型包。

操作流程：

1. 安装并校验说话人模型包。
2. 点击「开始本地分析」。
3. 选择一条字幕。
4. 在「当前字幕说话人」中检查或修改关联。
5. 将匿名名称改为「主持人」「嘉宾」等显示名。
6. 同一人被识别为多个身份时执行合并。

自动关联依据是说话区间与字幕时间的最大重叠。多人抢话、短句和边界位置需要人工试听。改名、合并和重新分配会创建可恢复版本。

### 5.4 词级时间

选择包含词级时间的字幕后，可以查看每个词的文本、开始时间、结束时间和转写置信度。

创建词范围软剪辑：

1. 点击第一个词。
2. 再点击结束词。
3. 调整起点和终点把手。
4. 选择 `30 ms`、`100 ms` 或 `200 ms` 安全留白。
5. 点击「创建并试听」。
6. 在「审阅」中决定是否应用软剪辑。

创建操作只生成待审剪辑并播放预览，不会立即删除内容。应用软剪辑后，原片仍保持不变，导出时根据时间映射跳过对应范围。

## 6. 历史

「历史」显示项目的可恢复版本，例如：

- 编辑字幕。
- 拆分或合并字幕段。
- 调整字幕时间。
- 应用 Agent 建议。
- 应用或恢复软剪辑。
- 修改说话人名称或关联。
- 更新字幕样式。

点击历史版本会将项目恢复到该版本。恢复前应确认当前尚未保存的界面输入已经处理。

历史恢复只影响项目数据，不会覆盖或删除原始媒体。

## 7. 导出

「导出」用于选择字幕轨、字幕样式、画布和文件格式，并执行导出前检查。

### 7.1 字幕导出

支持：

- SRT
- VTT
- ASS
- Markdown
- 结构化 JSON

可选择原文字幕、译文字幕或双语字幕。译文存在过期段或质量失败段时，需要先更新译文，或明确确认仍使用当前译文。

### 7.2 视频导出

视频导出支持：

- 保留原始画面比例。
- 使用 `9:16` 竖屏画布。
- 将原文、译文或双语字幕烧录进 MP4 画面。
- 将字幕作为 `mov_text` 文本轨内嵌到 MP4。
- 将字幕作为 `SubRip` 文本轨内嵌到 MKV。
- 在 MP4 旁生成同名 UTF-8 SRT 或 VTT 文件。
- 应用已经确认的软剪辑。
- 显示字幕安全区。

字号、描边、位置、字幕框尺寸和安全区设置只作用于烧录模式。字幕框宽度可在画面宽度的 50% 至 96% 之间调整；拉宽后每行可显示更多文字。字幕框高度可设置为 2 至 6 行；拉高后预览区可显示更多字幕行。调整字幕框不会删减或改写字幕正文，导出仍保留完整文本。

内嵌字幕轨和外置字幕文件保留文本与时间码，显示样式由播放器或导入平台决定。

SRT 字幕块之间使用一个空行分隔，VTT 文件包含标准 `WEBVTT` 文件头。外置字幕与视频使用相同文件名，扩展名分别为 `.srt` 或 `.vtt`。

项目未应用任何剪辑时，导出视频与原片等长，界面会要求明确确认。

导出前会检查：

- 原始媒体是否存在且 SHA-256 一致。
- 字幕时间是否有效。
- 译文是否完整或过期。
- 词范围剪辑是否仍与当前字幕和词级时间一致。
- 输出目标是否可写。

导出生成新文件，不覆盖原始媒体。

## 8. 隐私与安全边界

- 媒体、字幕数据库和模型保存在本机。
- Agent 载荷只包含文本、时间戳、任务说明和结构约束。
- Agent 结果必须进入人工审阅。
- 模型和运行时只有在明确选择后才会下载。
- URL 导入不会读取浏览器 Cookie、浏览器配置或插件。
- 原片缺失或内容变化时，SHA-256 审计会阻止不可靠导出。
- 公共问题报告不得包含真实媒体、字幕正文、本机绝对路径、账户名称或个人信息。

## 9. 常见问题

### Agent 完成多个批次后显示「运行失败」

先展开「技术详情」确认失败原因。相同项目版本和批次范围下，「显式继续」会复用已经完成的安全批次，不会从第 1 批重新运行。

如果提示项目版本变化，需要重新创建任务。旧结果不会覆盖当前文稿。

### 「分析」中没有语音节奏

当前字幕缺少可信的词级时间。使用支持词级时间的本地转写后重新检查。MOSS 多人长音频转写当前不提供词级时间，因此词范围剪辑不可用。

### 音频质量风险无法定位到具体声音

静音风险可以定位到具体区间；综合响度和真峰值是全片统计。需要结合播放器和外部音频工具进一步检查。

### Agent 建议是否会直接修改字幕

不会。Agent 建议先进入「审阅」，只有点击「应用建议」或「全部应用」后才会写入项目。

### 原片是否会被软剪辑覆盖

不会。软剪辑只修改项目时间映射，原始媒体保持不变。
